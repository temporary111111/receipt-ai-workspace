## Dataset Composition

This dataset is a multi-domain bennchmark for detecting AI-generated text-rich images from GPT-Image-2.

The dataset consists of two complementary subsets:

1. Fake subset:
Images generated by GPT-Image-2 using carefully designed prompts. The prompts are constructed to cover diverse domains and layouts while avoiding reproduction of specific real-world images.

2. Real subset:
Images sampled from six publicly available datasets. These images are selected as real-world references to provide natural examples of text-rich visual content.

The final dataset contains 6,109 synthetic images and 5,986 real images.

## Dataset Structure 

The dataset is organized hierarchically by image category and authenticity label:

```

├── AcademicPosters/
│ ├── 0_real/

├── CommercialPosters/

│ ├── 0_real/
```

### Source Data


The Real subset is constructed by sampling images from six publicly available datasets:

| Subset | Source Dataset | License |
|---|---|---|
| Real/AcademicPosters | [PosterSum](https://huggingface.co/datasets/rohitsaxena/PosterSum) | -- |
| Real/CommercialPosters | [Crello](https://huggingface.co/datasets/cyberagent/crello) | CDLA-Permissive-2.0 |
| Real/InfographicCharts | [ChartGalaxy](https://huggingface.co/datasets/ChartGalaxy/ChartGalaxy) | Apache 2.0 |
| Real/Receipts | [SROIE](https://rrc.cvc.uab.es/?ch=13&com=introduction) | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| Real/Tables | [PubTables-1M](https://huggingface.co/datasets/bsmock/pubtables-1m) | CDLA-Permissive-2.0 |
| Real/UIScreenshots | [Enrico](https://github.com/luileito/enrico) | MIT |

Only a subset of images from each dataset is included in this dataset. The original datasets are not redistributed in their entirety.
The included real-world images remain subject to the original licenses of their respective source datasets. Users should refer to the original datasets for license terms and usage conditions.
